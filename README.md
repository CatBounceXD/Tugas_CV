# CV Website - Steven Pratama

Website CV responsif ini dibangun sebagai Tugas Praktikum Front-End Development. Proyek ini menampilkan informasi personal, riwayat pendidikan, pengalaman organisasi, daftar keahlian, dan proyek-proyek yang telah dikerjakan.

## Live Preview
https://catbouncexd.github.io/Tugas_CV

## Fitur Utama
* **Desain Responsif:** Tata letak website dapat menyesuaikan secara otomatis baik saat dibuka melalui pc maupun di hp.
* **Mode Gelap Minimalis:** Menggunakan kombinasi warna gelap dengan aksen Teal dan Kuning yang modern.
* **Glassmorphism UI:** Desain kartu (card) menggunakan efek kaca transparan untuk tampilan yang elegan.
* **Navigasi Hamburger:** Menu navigasi yang akan berubah menjadi ikon hamburger interaktif pada layar berukuran kecil.
* **Smooth Scrolling:** Transisi pages yang halus saat berpindah antar bagian (section) melalui menu navigasi.

## Teknologi yang Digunakan
Proyek ini dibangun secara manual dari awal tanpa menggunakan framework tambahan, sesuai dengan ketentuan tugas:
* **HTML:** Untuk struktur dasar.
* **CSS:** Untuk penataan gaya, tata letak (Flexbox), animasi transisi, dan Media Queries.
* **Vanilla JavaScript:** Digunakan secara khusus untuk mengaktifkan fungsionalitas toggle pada menu hamburger.
